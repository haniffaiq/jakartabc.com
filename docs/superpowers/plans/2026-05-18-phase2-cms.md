# Phase 2 — CMS (Insights & Services) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Stand up the editorial CMS so non-dev editors publish bilingual Insights and update Service content without code changes, replacing MDX as source-of-truth for editorial content.

**Architecture:** Payload v3 collections in `packages/content` consumed by `apps/web` via Payload Local API (in-process, no HTTP); field-level localization stored in postgres `_locales` tables; on-demand revalidation via webhook from Payload `afterChange` hook to Next.js `revalidateTag()`; rich-text Lexical with custom blocks (`dropCap`, `pullQuote`, `regulationCite`).

**Tech Stack:** Payload v3 (`@payloadcms/db-postgres` + `@payloadcms/richtext-lexical`), `payload generate:types` codegen, next-intl 3, Vitest + Payload test helpers, Playwright.

**Prerequisite:** Phase 0 + Phase 1 complete. Postgres currently has only `SiteSettings` global; this plan adds all editorial collections.

```ts
// packages/content/src/hooks/readTime.ts
type LexicalNode = { type?: string; text?: string; children?: LexicalNode[] }
type LexicalRoot = { root?: { children?: LexicalNode[] } }

function flatten(node: LexicalNode | undefined, acc: string[]): void {
  if (!node) return
  if (typeof node.text === 'string') acc.push(node.text)
  for (const c of node.children ?? []) flatten(c, acc)
}

export function calcReadTime(body: LexicalRoot): number {
  const acc: string[] = []
  for (const c of body.root?.children ?? []) flatten(c, acc)
  const wc = acc.join(' ').trim().split(/\s+/).filter(Boolean).length
  return Math.max(1, Math.ceil(wc / 200))
}
```

```ts
import type { CollectionAfterChangeHook, GlobalAfterChangeHook } from 'payload'

export function makeRevalidateHook<TDoc = unknown>(buildTags: (doc: TDoc) => string[]) {
  const hook: CollectionAfterChangeHook = async ({ doc }) => {
    try {
      const tags = buildTags(doc as TDoc)
      const url = `${process.env.NEXT_PUBLIC_SITE_URL}/api/revalidate`
      const res = await fetch(url, {
        method: 'POST',
        headers: { 'content-type': 'application/json', 'x-revalidate-secret': process.env.REVALIDATE_SECRET ?? '' },
        body: JSON.stringify({ tags }),
      })
      if (!res.ok) {
        console.error('[revalidate] non-ok response', res.status)
      }
    } catch (err) {
      console.error('[revalidate] error', err)
    }
    return doc
  }
  return hook
}

export function makeGlobalRevalidateHook<TDoc = unknown>(buildTags: (doc: TDoc) => string[]): GlobalAfterChangeHook {

      })

    } catch (err) {
      console.error('[revalidate] global error', err)
    }

  }
```

```ts
// apps/web/src/app/api/revalidate/route.ts
import { revalidateTag } from 'next/cache'

export async function POST(req: Request) {
  const secret = req.headers.get('x-revalidate-secret')
  if (!secret || secret !== process.env.REVALIDATE_SECRET) {
    return new Response('unauthorized', { status: 401 })
  }
  let body: { tags?: string[] }
  try { body = await req.json() } catch { return new Response('bad json', { status: 400 }) }
  if (!Array.isArray(body.tags)) return new Response('bad body', { status: 400 })
  for (const tag of body.tags) {
    if (typeof tag === 'string' && tag.length > 0) revalidateTag(tag)
  }
  return Response.json({ revalidated: body.tags })
}
```

```tsx
import * as React from 'react'
import { Eyebrow, DisplayHeading } from '@jakartabc/ui'

type Node = any  // Lexical node shape; refine per generated types

export function RichTextRender({ content, regulations }: { content: { root: { children: Node[] } }; regulations: { id: string | number; code: string; url: string }[] }) {
  const lookupRegulation = (id: string | number) => regulations.find((r) => r.id === id)

  function renderNode(n: Node, i: number): React.ReactNode {
    if (n.type === 'paragraph') {
      return <p key={i} className="mt-6 max-w-prose text-body-md leading-relaxed text-ink-700">{(n.children ?? []).map(renderInline)}</p>
    }
    if (n.type === 'heading') {
      const tag = (n.tag as 'h2' | 'h3') || 'h2'
      return <DisplayHeading key={i} as={tag} size={tag === 'h2' ? 'md' : 'md'} className="mt-16">{(n.children ?? []).map(renderInline)}</DisplayHeading>
    }
    if (n.type === 'block') {
      const fields = n.fields as any
      if (fields.blockType === 'pullQuote') {
        return (
          <figure key={i} className="my-12 max-w-prose">
            <blockquote className="font-display text-display-md leading-[1.2] text-ink-900">{fields.quote}</blockquote>
            {fields.attribution && <figcaption className="mt-4 text-body-sm text-ink-700">— {fields.attribution}</figcaption>}
          </figure>
        )
      }
      if (fields.blockType === 'dropCap') {
        return <span key={i} data-dropcap aria-hidden /> // CSS uses ::first-letter on the next paragraph
      }
      if (fields.blockType === 'regulationCite') {
        const reg = lookupRegulation(fields.regulation?.id ?? fields.regulation)
        if (!reg) return null
        if (fields.inline) {
          return <a key={i} href={reg.url} className="text-ochre-700 underline-offset-4 hover:underline">{reg.code}</a>
        }
        return (
```

```ts
  const existing = await payload.find({ collection: 'categories', where: { slug: { equals: c.slug } }, limit: 1 })
  if (existing.docs.length > 0) return existing.docs[0]
  return payload.create({ collection: 'categories', locale: 'en', data: { slug: c.slug, name: c.name.en } })

async function upsertAuthor(payload: Payload, a: typeof AUTHORS[number]) {
```

```markdown
# Admin Onboarding — jakartabc.com CMS

This guide is for editors and partners who manage content via the Payload admin at `https://jakartabc.com/admin` (or `https://staging.jakartabc.com/admin` during testing).

## 1. Logging in

Your admin account is provisioned by an existing admin. First-time login requires the email + temp password sent to you. Change your password immediately under your user profile (top-right avatar).

## 2. Roles

v1 has two roles: **admin** (full CRUD on all collections) and **editor** (CRUD on Insights, Services overview, Media, Authors, Categories, Regulations). Partner-level access for sales workflow on `BookingLeads` is added in Phase 3.

## 3. Publishing an Insight (bilingual)

1. **Collections → Insights → Create New**
2. Fill the EN fields (default locale):
   - **Slug** — URL-friendly, all-lowercase, dash-separated (e.g., `bkpm-reg-5-2025-what-changes`). Do **not** translate the slug — it stays English across locales.
   - **Title**, **Lead**, **Body** (Lexical editor), **Category** (relationship), **Author** (relationship)
   - **Cover Image** (optional) — must have alt text (you'll be prompted)
   - **Regulations Cited** — add the BKPM/UU/etc. references you mention. These render as a footer block on the public page.
   - **Published At** — date you intend to publish (drives sort order)
   - **Status** — leave `draft` until ready
3. **Switch locale to ID** (header dropdown) and fill the Indonesian Title, Lead, Body. Lexical blocks (drop cap, pull quote) translate independently.
4. Save. Verify on `/insights/{slug}` (EN) and `/id/insights/{slug}` (ID).
5. When ready, change **Status** to `published`. Revalidation fires automatically.

## 4. Drop cap, pull quote, regulation cite

In the Lexical body editor, click the **+** menu → choose **dropCap** (mark next paragraph), **pullQuote** (large editorial quote), or **regulationCite** (reference to a Regulation by code).

## 5. Editing Services

Services are the four core service detail pages. They have many array fields: `whoFor`, `requirements`, `timelineSteps`, `faq`. Each array supports adding/removing rows and reordering.

- **timelineSteps** has a `who` select: choose `we` (we handle), `joint` (joint), or `you` (you provide). The label localizes via the i18n JSON in code (we_label / joint_label / you_label).
- **pricing.govFee** + **pricing.ourFee** are integers in IDR (no decimals).
- Editing any Service triggers revalidation of `/services`, `/services/<slug>`, and `/pricing`.

## 6. Adding a Regulation

Regulations have a globally unique **code** (e.g., `BKPM Reg 5/2025`). When citing in an Insight or Service, you pick by code from a dropdown.

## 7. Image alt text — required

Every Media upload must have alt text. The form will refuse to save without it. **This is a hard accessibility requirement, not a soft suggestion.** Write alt text that describes what the image shows, not what it represents stylistically.

## 8. Translation workflow

The site is bilingual EN/ID from day one. The convention:

- Content team owns EN as the source of truth
- Translator updates ID fields per content item
- Admin lists show a small badge when ID locale is missing for a published item — please complete before launching the article
```
